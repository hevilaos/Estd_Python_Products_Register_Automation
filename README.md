# Estd_Python_Products_Register_Automation

## Português

Projeto de prática de Python que automatiza o cadastro, em um site, dos produtos listados em `produtos.csv`.

Os cliques e outras definições foram feitos considerando o contexto local em que a automação foi executada; podem precisar de ajustes em outros ambientes. A automação parte do princípio de que o navegador não está aberto na página do site.

## English

A Python study project that automates registering the products listed in `produtos.csv` on a website.

The click coordinates and other settings were defined for the local environment where the automation ran and may need adjustments elsewhere. The automation assumes the browser is not already open on the website.
